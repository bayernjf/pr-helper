Privacy Policy

Last updated: July 31, 2026

PR Helper ("we", "our", or "us") is a GitHub-first PR and Release Control Tower. This Privacy Policy explains what data we collect, how we use it, and your rights.

1. Data We Collect

  • GitHub Account Information: Your GitHub login name, user ID, and avatar URL, obtained through GitHub App OAuth authorization.
  • Workflow Configuration: Repository names, branch names, stage configurations, and deployment settings you create within the application.
  • Monitoring Data: Pull request status, GitHub Actions run results, deployment states, webhook events, and reconciliation telemetry.
  • Local-Only Data: PR drafts and Markdown generation rules are stored in your browser's localStorage and are not uploaded to our servers by default.

2. How We Store Your Data

  • Server-Side Data: Workflow configurations and monitoring state are stored in Supabase (PostgreSQL), hosted on AWS infrastructure.
  • Encrypted Cloud Sync (Optional): If you enable cloud sync, your local data is encrypted with AES-GCM 256-bit encryption using a passphrase you provide. We store only the encrypted ciphertext; we cannot decrypt your data.
  • Session Data: Authentication sessions are stored in signed, HTTP-only, secure cookies.

3. What We Do NOT Collect

  • We do not collect or store your GitHub App private keys or installation tokens on the server beyond short-lived runtime generation.
  • We do not store your AI API keys on the server; they are kept only in your browser session.
  • We do not use analytics, tracking cookies, or third-party data collection SDKs.
  • We do not collect your IP address or browsing history beyond standard hosting infrastructure logs.

4. Third-Party Services

  • GitHub: We interact with GitHub's API using GitHub App installation tokens. GitHub's privacy practices apply to your GitHub data.
  • Vercel: Our API and frontend are hosted on Vercel. Vercel's data processing agreement applies.
  • Cloudflare Pages: A static mirror of the frontend is served via Cloudflare Pages. Cloudflare's privacy policy applies.
  • Supabase: Database storage is provided by Supabase (AWS-hosted). Supabase's security and compliance practices apply.

5. GitHub App Permissions

Our GitHub App requests the following permissions:

  • Actions (Read & Write): To read workflow run status, rerun failed Actions, and trigger rollback workflows.
  • Contents (Read-only): To read branch information and compare changes.
  • Pull Requests (Read & Write): To create, read, and merge pull requests on your behalf.

You can review and revoke these permissions at any time through your GitHub Settings → Applications.

6. Data Retention and Deletion

You can delete your account and all associated data at any time by clicking "Delete Account" in the application's account menu. This will permanently remove:

  • Your user record
  • All workflow configurations
  • All monitoring state, events, and deployment history
  • All encrypted sync data
  • All push notification subscriptions

7. Your Rights

You have the right to:

  • Access your data through the application interface
  • Export your workflow configurations
  • Delete your account and all data at any time
  • Revoke GitHub App access through GitHub Settings

8. Contact

For privacy concerns or questions, please open an issue on the project's GitHub repository.
